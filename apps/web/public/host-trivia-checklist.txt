Host Trivia Night Checklist (Quivio)

Before the event
- Pick 4–6 topics matched to your audience (mix easy and hard)
- Create a room (public for open joins; private for a set list)
- Share the PIN + start time; ask players to test audio/chat
- Prepare 1–2 icebreaker questions

During the game
- Explain rounds, time per question, and scoring
- Keep pacing tight; short breaks between questions
- Celebrate close scores; spotlight great answers
- Moderate chat; resolve disputes quickly

After the game
- Share the final leaderboard and shoutouts
- Gather feedback (topics, pacing, difficulty)
- Save strong questions to reuse later
- Rotate topics for the next session
